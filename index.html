🌐 Publicar el diagnóstico en línea

Para tener un enlace propio que puedas compartir con cada emprendedor, tienes dos opciones gratuitas y muy fáciles:

⚡ Opción 1: Netlify Drop (la más rápida — 2 minutos)

  1. Ve a app.netlify.com/drop
  2. Arrastra el archivo diagnostico-modo-emprendedor-v2.html a la zona gris
  3. ¡Listo! En segundos tienes una URL como: amazing-fox-12345.netlify.app
  4. Para una URL más bonita, crea cuenta gratis y renómbrala a algo como diagnostico-modo-emprendedor.netlify.app

🐙 Opción 2: GitHub Pages (URL permanente)

  1. Crea cuenta en github.com (gratis)
  2. Crea un repositorio nuevo (nombre ej: diagnostico-ia)
  3. Sube el archivo HTML como index.html
  4. Ve a Settings → Pages → Source: "main" → Save
  5. URL resultante: tu-usuario.github.io/diagnostico-ia
